# 路线图看板 UI 优化设计 (Tesla-style Bento Box)

> **状态：已废弃。** 旧 `docs/pinganpi-roadmap-dashboard.html` 静态页面已删除，不再维护。后续 roadmap 可视化只使用 `roadmap-viewer/`。

## 设计意图 (Intent)
将 `docs/pinganpi-roadmap-dashboard.html` 从传统静态文档流页面升级为具有前沿现代感的交互式 Dashboard。因为这是独立于主工程的内部开发者看板，因此不需要遵循主项目的“复古账簿”风格。

根据讨论，确定采用 **Tesla-style (Cyber-Industrial)** 结合 **Bento Box (左侧通栏)** 的布局结构。

## 核心设计方向

### 1. 结构 (Architecture) - 侧栏通顶便当盒 (Tall Sidebar Bento)
- **左侧通栏区块**：作为阶段（Phase 1 - 33）的时间轴/列表。这个区块内部支持独立纵向滚动（Scrollable Area），以适应未来可能增加到 50+ 个阶段。
- **右侧网格区块**：由一系列大小不一、紧密排列的方形/矩形卡片组成，分别承载：
  - 核心指标（当前基线、验证状态、下一推荐、主要风险）
  - 近期验证快照日志
  - 文档快捷入口
  - （可选）其他风险提示条目

### 2. 视觉风格 (Visual Style) - 特斯拉暗黑工业风 (Cyber-Industrial)
- **背景与色调**：
  - 整体页面背景为深灰色或纯黑色（例如 `#000` 或 `#0f0f0f`）。
  - 卡片底色为极深的枪灰色（例如 `#1a1a1a`），没有柔和的过渡渐变，不使用毛玻璃效果。
- **形状与边框**：
  - 去除大圆角，使用直角或极小的圆角（例如 `2px - 4px`）。
  - 卡片之间的缝隙（gap）非常细（例如 `2px` 或 `4px`），或者使用 1px 的硬边框（如 `#333`）来分割模块。
- **排版与字体**：
  - 大量使用大写的无衬线字体或等宽字体（Monospace）作为标签说明（如 `PHASE PROGRESS`）。
  - 核心数据使用极粗、紧凑的无衬线数字字体。
- **指示状态的色彩**：
  - 极度克制用色。去除非必要的蓝/绿/黄背景色。
  - 完成状态：纯白色。
  - 活跃状态（当前进行中）：高对比度的亮蓝色。
  - 警告/风险：高对比度的红色或橙色。

### 3. 组件重构 (Component Refactoring)
*需修改现有的 HTML/CSS 代码：*

1.  **CSS Root Variables 重构**：
    *   移除所有的 `-soft` (如 `--blue-soft`) 颜色，只保留高对比度的单色。
    *   将 `--bg` 修改为 `#000000`。
    *   将 `--surface` 修改为 `#111111` 或 `#1a1a1a`。
    *   将 `--ink` 修改为 `#ffffff`。
2.  **布局调整 (Grid)**：
    *   根容器设置为全屏高度（`100vh`）或固定的高视窗结构，避免整个页面滚动，将滚动限制在左侧列表内。
    *   使用 `display: grid; grid-template-columns: 320px 1fr; gap: 8px;` （或类似比例）的根网格。
3.  **阶段列表 (Phase List)**：
    *   去掉“绿块白字”的设计，改为暗色底块加上白色/灰色的粗体文字。
    *   左侧列表加入 `overflow-y: auto;`。
4.  **徽章 (Badges)**：
    *   去掉半透明的彩色背景，改为只有 1px 细线边框或者纯色块的硬核指示器。

## 验收标准 (Acceptance Criteria)
1. 页面能在浏览器正常打开。
2. 整体呈现强烈的暗黑极客工业风（Tesla-style），去除了圆润感和复杂的阴影。
3. 布局改为左侧长列表（可独立滚动），右侧为网格数据。
4. 不破坏或丢失原本存在的任何路线图进度数据（阶段 1-33 及已完成能力）。
